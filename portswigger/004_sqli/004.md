# Lab: SQL injection attack, querying the database type and version on MySQL and Microsoft
Category: SQL Injection / XSS / Auth / etc.
Date completed: 2026-05-16
Status: Solved

## What I Learned

- The comment token for a MS/MYSQL DB has a space after it: `-- `
- The `@@VERSION` is returned as a one-column field; we can populate two columns by: `SELECT @@VERSION,NULL -- `
- For UNION attacks, the big challenge is picking the right number of columns, and determining the table and column names to pull from. But in this case, we use `@@VERSION` which only fills one column.

## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.
