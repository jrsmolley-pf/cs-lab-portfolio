# Lab: SQL injection attack, listing the database contents on non-Oracle databases
Category: SQL Injection
Date completed: 2026-05-16
Status: Solved

## What I Learned

- For non-Oracle databases we can SELECT the columns named `TABLE_NAME` and `COLUMN_NAME` from the `information_schema.columns` system table!
- We can use the SQL `WHERE TABLE_NAME LIKE '%foo%'` to help filter a large set of returned values
  
## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.
