# Lab: SQL injection attack, listing the database contents on Oracle
Category: SQL Injection
Date completed: 2026-05-16
Status: Solved

## What I Learned

- For Oracle databases, we start our table and column search with `SELECT TABLE_NAME FROM all_tables`, then, `SELECT TABLE_NAME,COLUMN_NAME from all_tab_columns`
- Whereas for non-oracle databases, we use the tables `information_schema.tables` and `information_schema.columns`.
  
## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.
