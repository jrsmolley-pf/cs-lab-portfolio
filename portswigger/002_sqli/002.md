# Lab: SQL injection vulnerability allowing login bypass
Category: SQL Injection
Date completed: 2026-05-16
Status: Solved

## What I Learned

- When adding tokens such as `'--` to input fields like a username, if a server is vulnerable (does not sanitize this input) and pastes it directly into a db query, it can have the effect of commenting-out filter conditions, effectively retrieving information that should not be retrieved.
  
## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.

## Notes

- Sometimes it isn't enough to add the characters in the browser URL box (because this sends a HTTP GET request), if I need to make a HTTP POST request for something like a login, I'll need to fill out the form fields of the web page and submit it that way, or use a tool like cURL. ie:
