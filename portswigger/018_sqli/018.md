# Lab: SQL injection with filter bypass via XML encoding
Category: SQL Injection
Date completed: 2026-05-15
Status: Solved

## What I Learned
Injecting with obfuscation via XML:

- UNION just stacks table rows vertically. It is necessary to determine how many columns are being returned by a query before using the UNION operator, because we must SELECT the same number of columns for the second part of the UNION.
- We can determine the number of columns the query is returning by executing the SQL `' ORDER BY 1--`, then 2, 3, etc.
- I can select multiple columns and concatenate them (`a || '~' || b` worked here)
- Characters in XML injection must be obfuscated with `&#xHH;` where `HH` is the hexadecimal ASCII code. WAF's may detect suspicious tokens (dash, grave, tilde, and SQL keywords) and block requests.
- Unlike in URL query parameters, you cannot escape characters in the form `%55` in XML.
- Doublecheck your ASCII hex codes!
  
## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.
