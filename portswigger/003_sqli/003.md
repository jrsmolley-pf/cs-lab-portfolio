# Lab: SQL injection attack, querying the database type and version on Oracle
Category: SQL Injection
Date completed: 2026-05-16
Status: Solved

## What I Learned

- UNION attacks begin by figuring out the number of columns the first part of the query is returning
- The table name MAY be V_$VERSION
- This table MAY be in the `all_tables` table
- But if not, we will need to look at the `all_tab_columns` table, specifically the `table_name` and `column_name` columns.
- Ultimately we need the column names in order to SELECT data from tables.
- To select N columns of data from a source that has fewer than N columns, we add padding: `SELECT NULL,NULL,colname,NULL,NULL` as needed
- Some of this may be Oracle-specific.
  
## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.

## Fix / Prevention

Query parameters retrieved from URLs (or any payloads) MUST be sanitized and SQL queries must be carefully crafted before execution!
