# Lab: SQL injection vulnerability in WHERE clause allowing retrieval of hidden data
Category: SQL Injection
Date completed: 2026-05-16
Status: Solved

## What I Learned

Assume the server makes an SQL query using the parameters provided in the HTTP request URL:
https://0ae7009e03c2f8fb802199ac003800df.web-security-academy.net/filter?category=Accessories
  
- Add the characters `'+OR+1=1--` in the same way --> If parsed directly as an SQL command, this will attempt to terminate the string "Accessories" with a dash `'`, add an OR (true) condition so that the entire WHERE clause evaluates to true, and then terminates the SQL command early with the `--` comment token. Altogether, this basically nullifies the WHERE filter and causes the query to be executed on all database rows.
```
https://0ae7009e03c2f8fb802199ac003800df.web-security-academy.net/filter?category=Accessories%27+OR+1=1--
Result: I found the unreleased products
```

## Root Cause

Parsing the HTTP request URL and parameters and sending them directly in an SQL request without sanitization/transformation.
